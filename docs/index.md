# Vibranium

Vibranium is an opinionated, self-maintained desktop configuration system — essentially **dotfiles on steroids**.  
It is designed to be fast, extensible, and configurable. Vibranium is built on top of [Arch Linux](https://archlinux.org), [Hyprland](https://hypr.land),  
and a collection of utilities that work together to provide a complete desktop experience.  
Vibranium is not an operating system. It is a configuration layer built on top of a standard Arch Linux installation.

## What it provides

Vibranium comes with carefully selected defaults designed to work out of the box with minimal manual configuration.

It provides a unified way to configure your desktop environment through its own configuration system, allowing you to manage appearance, behavior, and workflow settings from a single interface.
The goal is to provide a desktop that is ready to use while remaining fully understandable and customizable.

## Philosophy

Vibranium is inspired by, but not derived from, [Omarchy](https://omarchy.org/).  
It shares some ideas and parts of its approach, but Vibranium has its own [philosophy](understanding/philosophy.md), design decisions, and goals.  
Vibranium is an independent project. It is not commercially backed, does not have major sponsors, and is developed around a small but growing community.

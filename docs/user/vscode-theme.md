# VS Code theme

Vibranium can keep your editor's color theme synchronized with your desktop theme.

The following editors are supported:

- VS Code
- VS Code Insiders
- VSCodium
- VSCodium Insiders
- Cursor

When synchronization is enabled, changing your Vibranium theme automatically updates the editor theme.

## Enabling synchronization

Theme synchronization is disabled by default.

To enable it:

1. Open your editor's **Extensions** view.
2. Find the **Vibranium** extension.
3. Enable it.

If the extension is not already installed, Vibranium installs it automatically when needed.

Once enabled, every Vibranium theme change is automatically reflected in the editor.

## Notes

- If multiple supported editors are installed, all of them are kept synchronized.
- Theme changes are applied automatically without requiring additional configuration.

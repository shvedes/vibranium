# Vibranium

Vibranium is an opinionated Arch Linux desktop configuration built on [Hyprland](https://hypr.land/) and [Wayland](https://wayland.freedesktop.org/). It provides a complete, cohesive environment: themes, a status bar, notification handling, screenshot tools, a screen recorder, package management helpers, and a unified rofi-based configuration menu system — all tied together by a small runtime of Bash scripts. Vibranium is not an OS and never will be.

Vibranium was inspired by the [Omarchy](https://omarchy.org/) project, which is why you can regularly see echoes of Omarchy in the project’s structure or code snippets. Despite this, Vibranium was written from scratch and is not a direct fork or clone of Omarchy. 

Vibranium does not try to be like Omarchy; it does not attempt to replicate its behavior exactly. It has its own pros, its own cons, and its own philosophy.

This page is a starting point. To learn more about Vibranium, you'll find an overview of all the Wiki articles below.

Vibranium uses [Hyprpicker](https://github.com/hyprwm/hyprpicker) as a color picker.
The script `vb-core-color-picker` is responsible for the logic.

You can access it in two ways: 
- By clicking on the droplet icon in the bar
- By pressing (`CTRL + ALT+ C`)\*

Configuration is done via: *Vibranium Menu* -> *Setings* -> *Color Picker*.

> [!NOTE]
> If you want to change this shortcut, please read [Customize Keybindings](Customize%20Keybindings.md).

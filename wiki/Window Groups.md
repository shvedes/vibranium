> Related Hyprland wiki page: https://wiki.hypr.land/Configuring/Basics/Variables/#group

A window group is a collection of windows that share the same screen space as a single window. You can create a group by pressing `SUPER + G`.

After creating a group, you’ll see a small indicator at the top. Open another window, and it will appear in the same location as the previous one, with an additional indicator showing that it belongs to the group.

To switch between grouped windows, use `ALT` and the directional keys (`J/I/K/L`). To jump directly to a specific window, use `ALT` together with the number row (for example, `ALT + 2` focuses the second window in the group).

A group can also be locked, which prevents new windows from being added to it. To lock a group, press `SUPER + CTRL + G`. The border color will change to a blend of orange and red, indicating that the group is locked.

Once locked, any newly opened window will appear outside the group. To unlock it, press `SUPER + CTRL + G` again.

You can also manipulate windows inside a group: move them in or out, as well as rearrange them. For a complete list of group-related keybindings, search for `group` in *Vibranium Menu* -> *Help* -> *Keybindings*.

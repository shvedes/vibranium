All input is handled by the Wayland compositor, in our case *Hyprland*, which also means keyboard layouts are managed by it.

In Vibranium, you can set keyboard layouts easier than ever. Just like described in [Customize WM Appearance](Customize%20WM%20Appearance.md), go to:

*Vibranium Menu* -> *Settings* -> *Hyprland* -> *Input* -> *Keyboard Layouts*

Seeya 👋

PS. You can also adjust any input-related options there.

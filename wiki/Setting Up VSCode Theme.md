You can sync your Vibranium theme with VS Code, VS Code Insiders, Cursor, and VSCodium.

By default, theme synchronization is disabled, so you need to enable it manually. The theme extension is already installed for you; all that remains is to open the Extensions view in your editor and enable it.

Once enabled, Vibranium will keep your editor theme synchronized with the currently selected system theme.

One of the best parts of Vibranium settings is that you can adjust Hyprland configuration through simple Rofi-based menus. No need to open a text editor or search through documentation, just a straightforward interface.

The only time you’ll need to consult documentation is for more advanced options that Vibranium does not yet expose, such as custom shadow colors.

To configure most aspects of Hyprland’s appearance, go to:

*Vibranium Menu* -> *Settings* -> *Hyprland* -> *Appearance*

Here you can adjust *gaps* (including smart gaps), *shadows*, *blur*, *animations*, and general visual behavior such as window dimming.

For more advanced configuration, you can edit existing `.lua` files in:

```bash
~/.config/hypr/hyprland.conf.d/
```

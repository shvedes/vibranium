As mentioned in [Project Philosophy](Project%20Philosophy.md), Vibranium aims to be as minimal as possible out of the box. That said, it doesn’t mean you’re responsible for setting up everything yourself after a clean OS install.

In the Vibranium Menu (`CTRL ALT + V`), you’ll find a `Setup` section where you can choose between four options (at the time of writing):
- **[Secure Boot](Secure%20Boot.md)**
- **[Firewall](Firewall%20Setup.md)**
- **[Docker](Docker%20Setup.md)**
- **[QEMU](QEMU%20Setup.md)**

Each option will ask you essentially one question: whether you want to set it up or not. That’s all you need to do. The scripts behind these options handle the rest. You just wait, and once it’s done, you can start using what you’ve set up.

This makes the setup process as simple as possible. Plug and play.

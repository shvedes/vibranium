Typically, in Linux, you don't mess with cursor themes, instead, cursor themes are messing with you. Not in Vibranium though.

To set a cursor theme (or size), all you need to do is:

1. Download a cursor theme (`Vibranium Menu > Install > Package`)
2. Apply a cursor theme (`Vibranium Menu > Settings > Misc > Cursor theme`)

Selected cursor theme is applied instantly, no logouts or reboots required.

> [!NOTE]
> Some old X11 apps still need restart or even re-login in order to apply the new cursor theme (e.g. Steam).
